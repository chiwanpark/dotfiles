= Dotfiles

This repository provides a set of dotfiles with a configuration script `install`.
All files should be installed with the script.

= Configuration

* zsh
* neovim
* tmux
* ssh
* pip
* btop
* herdr
* niri
* waybar
* display-switch
* Karabiner-Elements

= Usage

[source,sh]
----
$ git clone https://github.com/chiwanpark/dotfiles.git ~/.dotfiles
$ cd ~/.dotfiles
$ ./install.sh
----

For Karabiner-Elements configuration, type the following commands:

[source,sh]
----
$ ln -s ~/.dotfiles/karabiner/complex.json ~/.config/karabiner/assets/complex_modifications/complex.json
----

For monospace fonts, run the following command:

[source,sh]
----
$ ./fonts/install.sh
----

= Display switching

The `display-switch` configuration changes the LG ULTRAFINE input when the configured USB receiver moves through the USB switch. It uses `lg-input-switch` because this monitor requires LG's vendor-specific DDC/CI input command rather than the standard input-selector command.

Run the dotfiles installer, then run the display-switch installer:

[source,sh]
----
$ ./install.sh
$ ./display-switch/install.sh
----
